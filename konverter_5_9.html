Klassen-Konverter

Wandelt eine .ods-Tabelle mit Lehrerkürzel + kommagetrennten Klassen in eine Zeile-pro-Klasse-Tabelle um (nur Klassenstufen 5–9).

🔒
Alles läuft nur in deinem Browser. Die Datei wird nicht hochgeladen und es werden keine Daten irgendwohin gesendet – nur die JavaScript-Bibliothek zum Lesen/Schreiben der Tabelle wird einmalig von cdnjs geladen.

1. Datei auswählen

📄 Klicke hier oder ziehe deine .ods-Datei hinein

2. Konvertieren

Erwartet wird: Spalte A = Lehrerkürzel, Spalte B = Klassen, kommagetrennt (z. B. „5a,5b,5c“). Ausgabe: Spalte A = Klasse, Spalte B = Lehrerkürzel — eine Zeile pro Klasse. Es werden nur Klassen übernommen, deren Bezeichnung mit einer Ziffer 5–9 beginnt.

Vorschau

Läuft vollständig lokal im Browser · keine Daten verlassen dieses Gerät
